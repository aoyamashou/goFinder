# goFinder

> 基于 [MyGo](https://mygo.egoist.dev/docs) 打造的Finder替代品，因为是狗大V做的Finder，中文名为狗方德。

goFinder 不是一个纯键盘驱动的硬核文件管理器，适合键盘和鼠标同时使用的用户。以简洁、高速、低资源占用为设计目标。
它把原生访达（Finder）和 [Yazi](https://github.com/sxyazi/yazi) 文件管理器的长处融在了一起。纯 Go 编写，用原生 UI 绘制界面，不用 cgo 和 WebView。

## 特点

### 如果你用惯了访达

goFinder 在访达的基础上增加了：

- **Yazi 式文件列表**：上级｜当前｜预览三栏并排，光标停在文件夹上就列出里面的内容，停在文件上就预览，0延迟，0等待。
- **极速过滤**：按 `f` 后边打字边过滤，1 万个文件也没有延迟。
- **拼音首字母搜索**：输入 `mxcx` 就能找到「模型查询.txt」。
- **单键快捷键**：`c` 拷贝、`v` 粘贴、`d` 移到废纸篓、`n` 新建文件夹、`↩` 重命名……常用操作都只要按一个键。所有的快捷键基于英语四级水平而设定，不需努力就能记住，且按 `?` 能打开快捷键速查表。



### 如果你用惯了 Yazi

goFinder 在 Yazi 的基础上增加了：
- **不用终端**：Yazi 的操作方式，跑在一个真正的 macOS 窗口里，不依赖 TUI。
- **方向键导航**：`↑↓` 移动，`→` 进入文件夹，`←` 返回上级。不需要去习惯Yazi原本的vim键位。
- **macOS 鼠标操作**：
  - 右键哪一项就先选中哪一项，双击打开；
  - 文件可以拖进拖出，和访达、其他应用互通；
  - 鼠标侧键和触控板轻扫用来后退、前进。
- **空格快速查看**：调用系统的 Quick Look，PDF、Office 文稿、视频、图片都能直接看。
- **拼音首字母搜索**：中文文件名也能快速过滤。
- **访达的那一套**：
  - 侧边栏跟随访达的个人收藏，外接磁盘可以一键推出；
  - 原生菜单栏；
  - 废纸篓（只移到废纸篓，从不永久删除）；
  - 可以设为默认的文件浏览器。

### AI友好
- 按a键，在当前目标文件夹处，启动你的 AI Agent。

### 其他
- 左右或上下双栏、暂存架、Workspace（多工作区切换）、按模板新建文件、像文件夹一样浏览 Zip、Git 状态标记。
- 右键菜单、快捷键和 shell 命令都可以自定义。
- 自动更新：从 GitHub Release 下载签名校验过的新版本。
-不支持多标签，因为本身已带双窗口模式，多标签没有意义。支持Workspace，可将常用的窗口/路径组合保存下来，一键调用。顶部标题栏右端每个工作区一个按钮（Agent 按钮在它们左边），也可以按 `1`–`9`、`[` `]` 切换；首次打开自带「默认工作区」（Home）、「下载」（左右双栏）、「文档」（上下双栏）三个演示工作区。按 `w` 或点工作区按钮打开管理对话框，可重命名、删除；右键工作区按钮也能重命名、删除。默认工作区只能改名，不能删除。

## 性能
在同一台 Mac 上，用同样的方法分别测了 goFinder和原生访达：

| 项目 | goFinder | 访达 |
|---|---|---|
| 打开窗口 | 冷启动 530–550 ms | 不存在冷启动，呼出一个新窗口 294–312 ms（首次 695 ms） |
| 空闲内存（phys_footprint） | **58 MB** | 183 MB |
| 空闲 CPU（60 秒内） | **0.08 s（约 0.1%）** | 0.22 s（约 0.4%） |
| 打开 1 万个文件的目录 | 读取并排序 25 ms，进入目录到画出第一帧约 45 ms | 新窗口出现要 311–547 ms |
| 处理这 1 万个文件耗费的 CPU | **约 0.4 s**（从启动到显示的全过程） | 1.3–2.1 s（打开后 10 秒内） |
| 显示这个目录时的内存 | **71–72 MB** | 约 240 MB |

结论：
- goFinder 冷启动比访达开新窗口慢约 0.2 秒，这是 MyGo 框架本身的启动成本。访达因为是系统应用，强制自动开启，不存在冷启动。
- 内存占用只有访达的约 1/3。
- 处理 1 万个文件用的 CPU 只有访达的 1/4 到 1/5。
- 列表进入稳定状态后，一个空闲帧约 0.18 ms，光标下移一行约 0.7 ms。

一切从省出发：不用 WebView，不加载系统文件图标（用本机的 Nerd Font 字形代替），只给屏幕上看得到的文件夹开文件监听，Quick Look 等光标停下来才生成预览。没有外部依赖，插件只有2个。

## 安装

- 下载：在 [Releases](https://github.com/aoyamashou/goFinder/releases) 下载 `.dmg`，把 goFinder 拖进「应用程序」文件夹。目前只有 Apple Silicon 版本。安装后，goFinder 会自动检查更新。
- 字体：列表图标用的是 `JetBrainsMono Nerd Font Mono`。如果没装，设置里可以一键下载；不装也能用，图标会退回文字符号。
- 签名：目前用的是自签证书，没有经过 Apple 公证。第一次打开时如果被系统拦下，到「系统设置 › 隐私与安全性」里点「仍要打开」。
- 解除隔离：如果提示「已损坏」或「无法打开」，可以先解除下载隔离（下载的 `.dmg` 也可以先这样处理再打开）：
  ```bash
  sudo xattr -r -d com.apple.quarantine /Applications/goFinder.app
  ```

## 键位

| 功能 | goFinder单键 | MacOS原生风格的第二键位 |
|---|---|---|
| 移动 / 打开 / 上级 | `↑↓` / `→` / `←` | — / `⌘↓` / `⌘↑` |
| 过滤（支持拼音首字母） | `f` | — |
| 快速查看 | `Space` | — |
| 拷贝 / 拷贝路径 / 剪切 / 粘贴 | `c` / `c c` / `x` / `v` | `⌘C` / `⌥⌘C` / `⌘X` / `⌘V` |
| 移到废纸篓（先确认） | `d` | `⌘⌫` |
| 新建文件夹 / 新建文件（按模板） | `n` / `n n` | `⇧⌘N` / `⌘N` |
| 重命名 | `↩`、`r` | — |
| 显示隐藏文件 / 排序 | `.` / `,` | `⇧⌘.` / — |
| 前往（输入路径） | `g` | `⌘L` |
| 回到起点（双栏各自记忆，默认 Home） | `` ` `` | — |
| 在终端打开 / 在这里打开 Agent | `;` / `a` | `⌥⌘T` / `⌥⌘A` |
| 在编辑器中打开 / 收藏当前文件夹 | `e` / `s` | — |
| 工作区对话框 / 切换工作区 | `w` / `1`–`9`、`[` `]` | — / `⌘1-9` |

- 只有 `c c` 和 `n n` 是同一个键连按两下（400 ms 内），其余都是单键。
- `⌘` 组合键是第二键位，原生菜单栏用的就是它们。
- 所有键位都可以在设置（`⌘,`）的「快捷键」页修改。

## 配置

数据目录在 `~/Library/Application Support/goFinder/`：

- `config.json`：终端和编辑器、是否显示隐藏文件、外观、右键菜单（`contextMenu`、`blankMenu`）、Agent、自定义 shell 命令（`commands`，可以用 `{path}`、`{selection}` 占位）。
- `keymap.json`：按动作 ID 覆盖快捷键，例如 `{"trash": ["Cmd+Alt+Backspace"]}`。动作 ID 见 `actions.go`，或在速查表里搜索。
- `templates/`：新建文件用的模板，每个文件就是一个模板。
- `shelf.json`：暂存架；`workspaces/`：保存的 Workspace。
- 收藏夹：有 iCloud 云盘时存在 `iCloud Drive/goFinder/favorites.json`，在多台 Mac 之间同步。
