# goFinder

轻量、键盘优先的 macOS 文件管理器，用 [MyGo](https://mygo.egoist.dev/docs) 原生 UI（纯 Go）编写。

## 运行

```bash
go tool mygo dev                 # 开发模式，改代码自动重启
go test ./...                    # 全部测试（界面测试不需要开窗口）
go tool mygo build -skip-installer   # 打包到 build/darwin-arm64/goFinder.app
```

## 已完成（阶段 0–5）

- Yazi 式界面（阶段 5，默认布局）：侧边栏｜上级文件夹｜当前文件夹｜第 4 栏。第 4 栏在光标停在文件夹上时列出它的子项，停在文本或图片上时显示预览，其他文件显示大图标、名称、大小和日期
  - QuickLook 预览（阶段 8）：PDF、HTML、Office/iWork 文稿、RTF、视频、HEIC/TIFF/SVG 等图片、字体等，由系统 `qlmanage -t` 生成缩略图显示在第 3 栏。光标停留 150ms 后才生成，超时 3s，失败或不支持时显示图标；缓存在 `~/Library/Caches/<id>/ql/`（键为路径+修改时间+尺寸，30 天未生成的启动时清理）；zip 内的文件先解压到缓存再生成。本机实测可预览：PDF、HTML、docx、RTF、TTF；损坏或伪造扩展名的文件会回退为图标
  - 列表只显示图标和文件名（无表头和大小/日期/类型列），字体默认 14pt（设置「通用」可调 13–18；字形比文字大 3pt）的 `JetBrainsMono Nerd Font Mono`（依次回退 `JetBrainsMono Nerd Font`、系统等宽字体）、行高 1.25；每栏宽度贴合本栏最长的文件名（120–300pt）；放不下的名字像 Yazi 一样从中间截断并保留扩展名（`build.gra….kts`），没有扩展名的截掉末尾（`StarDeskCompa…`）
  - 图标是 Nerd Font 字形，映射在 `internal/icons`（参照 Yazi 默认主题和 nerd-fonts 的 seti/dev/md/fa 字形，阶段 8 扩充）：语言与配置、文档、表格、演示文稿、图片、视频、音频、压缩包、磁盘映像、字体、证书和密钥、日志、数据库；`.app` 等包、可执行文件、符号链接；`.git`、`node_modules`、`.config`、桌面、下载、iCloud 等特殊文件夹；Git 仓库根目录用带 Git 标记的文件夹；隐藏项变暗。配色取中间亮度，深浅色模式都清晰
  - 字体不打包进 app；没装 Nerd Font 时回退为 `▸`/`▾` 文字符号。缺少 Mono 版时，设置「通用」页（以及状态栏的 `fontNotice`）提供"下载"：只在点击后从 nerd-fonts 官方 GitHub 下载 `JetBrainsMonoNerdFontMono-Regular.ttf` 和 `-Bold.ttf` 两个文件（各约 2.5MB）到 `~/Library/Fonts`，用 `ui.RegisterFont` 立即生效
  - 光标所在的文件夹、上级栏里当前所在的文件夹显示为"打开的文件夹"
  - 光标行和选中行：列表有键盘焦点时为强调色底，失去焦点（键盘在侧边栏、上级栏、窗口未激活）时为灰色底，文字保持原色
  - 当前接收键盘的栏位（侧边栏、活动窗格的当前列表）加强调色边框；单窗格时 `Tab` 在侧边栏和文件列表间切换，侧边栏里 `→`/`↩` 回到文件列表；双窗格时 `Tab` 切换窗格
  - 排序：列表没有表头，用菜单"显示 › 排序方式"
- 布局（阶段 7）：三列（默认，一个窗格）/ 左右双栏 / 上下双栏，**每个窗格都是完整的三列视图**（各自的上级栏、当前栏、第 4 栏和路径栏），侧边栏全局一个、作用于活动窗格。`⌘⌥3/2/4` 或状态栏右侧按钮切换；旧的单列表布局已删除，旧 Workspace 里的 `single` 读作三列。`⌘⌥P` 开关检查器（阶段 8，默认关闭）：作为约 200pt 宽的第 4 栏，只显示属性、不显示内容预览。文件：种类、大小、创建/修改/上次打开时间、权限（rwx、八进制、所有者/组）、路径、链接目标、Git 状态；文件夹：权限和统计（子项数、文件数/文件夹数、递归总大小，后台计算，最多统计 10 万项，超过显示 ≥）；多选时显示项数和总大小。阶段 9：除权限外每个值都可点击复制（悬停手形光标和浅色底，tooltip「点击复制」，复制显示的文字，状态栏提示「已复制 <字段名>」）；底部有「加入暂存架」和「打开暂存架 / 关闭暂存架」两个按钮
- 外观与标题栏：默认深色主题，不随 macOS 外观变化；设置（⌘,）「通用」页可改为浅色或跟随系统（`config.json` 的 `appearance`：`dark`/`light`/`system`）。窗口不用系统标题栏，由应用自己画一条标题栏（红黄绿按钮在其上，可拖动窗口，显示当前文件夹名），所以深色窗口在浅色 macOS 下也整窗深色；外观与系统不一致时侧边栏不用毛玻璃、改用实底
- 工具栏（阶段 7，阶段 12 重排，参照 QSpace，**默认隐藏**）：`⌃⌘B`、「显示」菜单或设置「通用」页的「显示工具栏」开关（`config.json` 的 `showToolbar`）；显示时工具栏即标题栏。SF Symbols 图标按钮，默认依次为后退、前进、上级｜新建（下拉：空白文件、各模板、新建文件夹）、排序（下拉）、显示隐藏文件｜移到废纸篓｜在终端中打开、在这里打开 Agent；右端是 Workspace、暂存架、过滤。上级在根目录时灰；移到废纸篓在没有选中项或在 zip 内时灰，悬停时图标变红，点击仍弹出删除确认；过滤生效时按钮为开启态，点击等同于 `f`。悬停显示名称和快捷键，作用于活动窗格。设置（⌘,）的「工具栏」页：左列是当前条目（上移、下移、移除，↑↓ 选行、⌘↑ ⌘↓ 移动、⌫ 移除），右列是可添加的条目，「恢复默认」把 `toolbar` 设为空（用默认工具栏）；每次改动立即写入 `config.json` 并刷新，不做拖拽
- 状态栏（阶段 8 起两行）：上一行左边是上一个操作的提示（不再显示项目数/已选数；过滤生效时显示"过滤：xx"），右边是视图切换（三列 / 左右 / 上下）和检查器开关（标签取动作标题），点击即执行对应动作；下一行整行是快捷键提示。显示隐藏文件只在工具栏（和 `.`、`⇧⌘.`）
- 文件行右键菜单（阶段 9）：用"复制路径"替代"在 Finder 中显示"（`reveal` 动作仍在原生菜单栏里）：复制所点文件的路径；所点文件在多选范围内时，复制全部选中项的路径（换行分隔）；复制后状态栏提示"已复制路径"
- 空白处右键菜单（阶段 7）：上级栏、当前栏、第 4 栏的空白处都能右键，作用于**这一栏显示的文件夹**：新建文件（子菜单：空白文件、各模板）、新建文件夹、粘贴、在终端中打开与各已启用 Agent（`@agents`，一级菜单项）、排序方式、显示隐藏文件、刷新、复制路径（复制这一栏所在文件夹的路径）；压缩包内的新建、粘贴不可用
- 在这里打开默认 Agent（阶段 7、阶段 10B，`a`，第二键 `⌘⌥A`；「文件」菜单、工具栏、右键菜单）：在设定的终端里运行 Agent 命令。目录：光标在文件夹上就是该文件夹，在文件上就是当前文件夹；没有已启用的 Agent 时状态栏提示"没有启用的 Agent，去设置 › Agent 启用"。做法是在缓存目录写 `agent/<哈希>.command`（首行用登录 shell，`#!$SHELL -l`，`$SHELL` 无效时用 `/bin/zsh`，保证 `~/.local/bin` 在 PATH 里；正文 `cd '<文件夹>' && exec <命令>`，文件夹按 sh 单引号转义，命令原样写入，每个文件夹+Agent 一个脚本），再 `open -a <终端> <脚本>`；终端的 `Info.plist` 没声明能打开 `.command` 时改用 Terminal，并在状态栏说明；不再读取 `agentCommand`。状态栏默认提示不含 `a`

- 方向键浏览：`↑↓` 移动，`→` 进入文件夹或打开文件，`←` 返回上级；`↩` 重命名，鼠标双击打开
- 拼音首字母过滤（阶段 17）：过滤词全小写时，中文名也按各字拼音首字母匹配，其他字符原样保留（「2026年报告」→ `2026nbg`）。码表由 `internal/pinyin/gen/gen.swift` 调 macOS 的 `CFStringTransform` 生成（`go generate ./internal/pinyin`），覆盖 U+4E00–U+9FFF；多音字只取系统默认读音（如「行」只认 x）

- 快捷键提醒：状态栏下一行是键帽式提示，平时依次显示 `f` 过滤、`c` 拷贝、`c c` 拷贝路径、`x` 剪切、`v` 粘贴、`n` 新文件夹、`n n` 新文件、`↩` 重命名、`d` 删除、`?` 帮助；按住 ⌘/⌥/⇧ 时按分组列出带这些修饰键的全部快捷键，放不下时截断；过滤输入时显示"过滤「xx」：n 项"和 `↩` `Esc`。`?` 打开只读、可搜索的速查表（同样的键帽），底部"在设置中修改"跳到设置的快捷键页
- 路径栏（阶段 6，QSpace 式一整条；阶段 7 起后退/前进移到工具栏）：每一级可点击，级间 `▸` 弹出该级的子文件夹；深层路径折叠为 `…`；`⌘L` 或点路径栏空白处输入路径并自动补全
- 文件拖放（阶段 6，Finder 规则）：三栏里的文件可拖到 Finder、其他应用或本应用的文件夹；可拖入文件夹行、栏的空白处、路径栏某一级、侧边栏条目和暂存架。同卷移动、跨卷复制，`⌥` 强制复制、`⌘` 强制移动；拖到自身或子文件夹、拖进 zip 会拒绝；zip 内的条目拖出时先解压再复制。拖放不改变键盘焦点和光标，本应用从不删除拖出的文件
- 过滤（阶段 9，复刻 Yazi 的 `filter --smart`）：按 `f` 在路径栏下出现输入框，边输入边过滤当前栏（名称包含该文字；输入全小写时不区分大小写，含大写字母时区分）；`↩` 保留过滤并回到列表，`Esc` 清除（输入框里、或过滤生效时在列表里都可以）；进入其他文件夹后自动清除；光标尽量停在原来那项上，被滤掉则在第一项。过滤时选择会被清空。多选用 `⌘A`、`⇧↑↓`、⌘ 点击（`/` 的快速选择已去掉）；在列表里直接打字不会触发过滤，单字母都是命令
- 标签页（`⌘T`/`⌘W`/`⌘1-9`）、`Tab` 切换窗格、后退/前进
- 拷贝/剪切/粘贴、重命名（`↩`/F2）、新建文件/文件夹、移到废纸篓、拷贝路径
- 删除确认（阶段 8）：`d`/`⌘⌫`（含右键菜单的"移到废纸篓"）先弹框"将 N 个项目移到废纸篓？"，列出最多 5 个名称，`↩` 确认、`Esc` 取消；勾选"不再提醒"后确认，会把 `config.json` 的 `confirmTrash` 写为 `false`，之后直接移到废纸篓；设置「通用」页可重新打开。拖到废纸篓不弹框
- 菜单风格（阶段 8）：右键菜单、空白处菜单、工具栏和路径栏的下拉都由 MyGo 在窗口内绘制（`SetMenuPresentation(PopoverMenus)`），每项右侧灰色显示该动作的第一键（同键双击显示下一个键），"移到废纸篓"为红色。原生菜单栏是系统 NSMenu，样式由 macOS 绘制、不能自绘，只在菜单标题里显示单键
- 一键在终端/编辑器中打开当前文件夹（`⌘⌥T`/`⌘⌥E`）
- 文件变化时自动刷新（只监听屏幕上可见的文件夹）
- 按模板新建文件：`n n` 或 `⌘N` 在光标处弹出"空白文件 + 模板"菜单，方向键选、`↩` 确认，再输入文件名（默认取模板名）
- `⌘,` 从已安装的应用里选终端和编辑器，写回 `config.json`；「Agent」页见下（阶段 10A）
- Zip 浏览：对 `.zip` 按 `→`/`↩` 像文件夹一样进入（路径形如 `/x/a.zip!/sub`），可排序、过滤、预览；包内 `↩` 解压到缓存目录再打开；`⌘C` 后到包外 `⌘V` 即解压；包内只读
- 侧边栏（默认显示，`⌃⌘S` 开关）跟随 Finder（阶段 6，只读，不写 Finder 的任何文件），带 SF Symbols 图标和窗口侧边栏材质：
  - 个人收藏：读 Finder 侧边栏的 `com.apple.LSSharedFileList.FavoriteItems.sfl4`（旧系统 `.sfl3`，再并入 iCloudItems 里的文件夹），条目、顺序和名称与 Finder 一致；跳过 Finder 隐藏的项、没有文件夹的项（AirDrop、最近使用、iPhone、网络）和已不存在的文件夹。在 Finder 里增删、拖动收藏后自动更新；读取失败时回退到主目录、桌面、下载、文稿、应用程序
  - 位置：iCloud 云盘、`~/Library/CloudStorage` 下的云盘（Google Drive 等）、Finder 会显示的外接卷（`/Volumes`，插拔自动刷新；不含启动盘、UUID 命名的卷和 Recovery 这类系统卷）
  - 收藏夹：本应用自己的收藏（`⌃⌘T` 收藏当前文件夹，`⌃⌘⌫` 或右键移除）
- 暂存架（右侧面板，`⌘⌥B` 开关）：`⌘⌥S` 加入选中项，或从 Finder 拖进来；`⌃⌘V` 全部拷贝到当前文件夹（暂存架保留），`⌃⌘M` 全部移动到当前文件夹（移走的离开暂存架）；按钮行（拷贝到此 / 移动到此 / 清空）在 220pt 面板内平分宽度、不再溢出，长文件名中间截断；每项可 `×` 移除，右键"在 Finder 中显示"；内容存 `shelf.json`，启动时去掉已不存在的项
- Workspace：`⌘⌥W`、右键菜单或菜单栏"窗口 › 保存/恢复 Workspace"打开对话框，把布局、两个窗格全部标签页的路径和排序保存为 `workspaces/<名称>.json`，或选一个一键恢复；已不存在的文件夹退到最近的上级。启动位置：命令行或系统"打开文件夹"指定的文件夹 > 右键文件夹选「启动时从这里开始」选定的文件夹（`config.json` 的 `startDir`，打勾表示已选，再选一次取消；文件夹不存在时忽略） > Finder「新建窗口时打开」的设置（`NewWindowTarget`：主目录、桌面、文稿、iCloud 云盘、电脑、指定文件夹）> 主目录 `~`，不再自动恢复上次的会话
- 收藏夹 iCloud 同步：有 iCloud Drive 时存到 `iCloud Drive/goFinder/favorites.json`，第一次启动把本地 `favorites.json` 合并进去并改名为 `favorites.json.migrated`；侧边栏显示时监听该文件夹，其他 Mac 的改动按"磁盘顺序为准 + 本机新增追加 + 本机删除生效 + 按路径去重"合并
- 自定义快捷键：`⌘,` 设置分「通用」「快捷键」两页；快捷键页按分组列出全部功能，可搜索，每行"改键"→ 按下任意键（单键也可以，`Esc` 取消）即生效并写入 `keymap.json`（被占用的键从原动作移走），录制中可"清除"或恢复"默认"；同键双击在 `keymap.json` 里写作 `"c c"`。`keymap.json` 或 `config.json` 里有冲突、未知动作或写错的键时，启动时状态栏提示，速查表顶部逐条列出哪条被忽略及原因
- 自动更新（阶段 18）：从 GitHub Release 下载经签名校验的更新（优先下载增量包）。启动 10 秒后检查一次，之后每天检查一次；也可以在应用菜单「检查更新…」或设置「关于」页的「检查更新…」手动检查。更新窗口提供安装、稍后提醒和跳过此版本。开发版不检查。
- 设置「关于」页（阶段 15）：版本（`mygo.json` 的 `version`，格式 `0.阶段.修订`）、构建（commit 短哈希 · 提交时间）、MyGo 版本、Bundle ID、数据目录（点击复制），以及「Debug 编号」开关（只在本次运行有效）；开启后各元素左上角显示固定编号，状态栏左侧出现「Debug」，点它关闭。编号表见 `docs/debug-ids.md`，沟通时说「30 号」「41·2 号」（后者是第 2 窗格）即可
- 自定义右键菜单、工具栏和 shell 命令（见下方配置）；自定义命令进入速查表和状态栏提示，可设快捷键，后台运行，失败原因显示在状态栏
- 设为默认文件浏览器：`⌘,` 设置里"设为默认 / 恢复 Finder"（写 `defaults -g NSFileViewer`，注销重新登录或 `killall Finder` 后生效）；应用声明了 `public.folder` 文档类型，系统让它打开文件夹时开新标签，打开文件时进入其所在文件夹并选中它。在列表里对 `.app` 按 → 、⌘↓ 或双击会直接运行它（同 Finder），不进入包内
  - 设置里有「复制命令」，把 `killall Finder` 写进剪贴板（不会在本机执行）；「完全磁盘访问」一行显示能否读 `TCC.db`，按钮打开系统设置的对应面板，开启后需重启 goFinder
  - 「在 Finder 中显示」诊断（阶段 14A，`docs/diag/reveal.swift` 只发 reveal 请求）：`lsregister -dump` 里 `dev.mygofinder.app` 同时登记了 `/Applications/goFinder.app`、各 worktree 与已卸载磁盘映像里的旧 `MygoFinder.app` 等十来个路径，系统可能把请求交给过期的路径。对策：设为默认时对当前 `.app` 执行 `lsregister -f`；`mygo.json` 加 `public.item` 文档类型（`LSHandlerRank: None`，不抢默认打开方式），让文件的 reveal 也能送达；收到路径后 `openPath` 进入上级并选中（已运行与冷启动都走 `OnOpenFile`）。**局限**：直接用 AppleScript 指名 Finder 的应用（`tell application "Finder"`）无法接管
  - **待真机确认**：①打包签名后运行，在 `⌘,` 设为默认并 `killall Finder`；②`swift docs/diag/reveal.swift ~/Downloads/某文件`，goFinder 应打开 `~/Downloads` 并选中该文件（先退出 goFinder 测冷启动，再开着测已运行）；③若仍不行，`lsregister -u` 清掉旧路径后重试，并看 `public.item` 是否真有帮助；④另一应用里右键「在 Finder 中显示」
- Git 状态：在仓库里时后台跑 `git status --porcelain=v2 --branch -z`（按仓库根缓存，同一仓库同时只跑一个，文件变化 300ms 防抖），文件名后标一个字母 `M`/`A`/`D`/`R`/`U`/`?`（未跟踪），含改动的文件夹标 `•`；地址栏显示 `⎇ 分支 · 改动数`。不在仓库或在 zip 内不运行 git；只读，不做 add/commit/push
- 原生菜单栏：所有功能都在菜单里（文件、编辑、显示、前往、暂存架、窗口、帮助，有自定义命令时多一个"命令"）；每项"一行字，一个键"：只显示该动作的第一键，与状态栏、右键菜单一致——第一键是能当菜单快捷键的 ⌘/⌃ 组合时作为菜单快捷键，否则（Yazi 单键、`↩`、`→`、`⌘⌫` 等）只写在标题后面，⌘ 第二键位不在菜单里显示、仍由窗口生效；改键后菜单随之更新；布局/预览/侧边栏/暂存架/隐藏文件带勾选标记。原生菜单栏是系统 NSMenu，不随右键菜单改为自绘；对话框或速查表打开时菜单项暂时停用

## 配置

数据目录：`~/Library/Application Support/goFinder/`
- `config.json`：
  - `terminal`、`editor`（应用名，传给 `open -a`，可用 `⌘,` 选择）、`showHidden`、`showSidebar`
  - `contextMenu`：右键菜单的动作 ID 列表，`"-"` 为分隔线；默认写入当前菜单
  - `toolbar`：工具栏项目列表，不写时用默认工具栏，写成 `[]` 隐藏工具栏。项目是动作 ID，或 `"-"`（间隔）、`"@new"`（新建下拉）、`"@sort"`（排序下拉）、`"@flex"`（把后面的推到最右），例如 `["back", "forward", "-", "@new", "layout.dual", "@flex", "shelf"]`；旧配置里的 `"@qs"` 会在设置里提示未知项并忽略。旧版本自动写入的 `"toolbar": []` 在没有 `version` 字段时视为默认工具栏
  - `blankMenu`：空白处右键菜单，写法同 `contextMenu`，另可用 `"@new"`（新建文件子菜单）、`"@sort"`（排序子菜单）、`"@agents"`（在终端中打开 + 已启用的 Agent）；不写时用默认菜单
  - `agents`：`{"<id>": {"enabled": true, "command": "…"}}`，每个已安装 Agent 的启用状态和命令；`command` 为空用默认命令（目录里的启动命令 + YOLO 参数，如 `claude --dangerously-skip-permissions`）。没有条目的 Agent 默认启用；`defaultAgent`：默认 Agent 的 ID，未设或不可用时取第一个已启用的
  - `agentCommand`：旧字段，只用于迁移（不是 `claude` 时写进对应 Agent 并设为默认）
  - `version`：配置格式版本，目前为 7
  - `commands`：自定义 shell 命令，例如 `{"id": "typora", "title": "用 Typora 打开", "command": "open -a Typora {selection}", "keys": ["Cmd+Alt+Y"]}`，动作 ID 为 `cmd.<id>`，可放进 `contextMenu`/`toolbar`。`{path}` 是当前文件夹，`{selection}` 是选中项（无选中时为光标项），都会逐个按 sh 规则加单引号转义，不必（也不要）自己加引号。命令用 `/bin/sh -c` 在当前文件夹后台运行
- `templates/`：新建文件的模板，每个文件就是一个模板，文件名即新文件的默认名；首次启动写入 `Untitled.txt`、`Untitled.md`、`main.go`
- `favorites.json`：侧边栏收藏夹 `{"folders": [...]}`；有 iCloud Drive 时改存 `~/Library/Mobile Documents/com~apple~CloudDocs/goFinder/favorites.json`
- `shelf.json`：暂存架 `{"items": [...]}`
- `workspaces/<名称>.json`：保存的 Workspace（旧版本留下的 `session.json` 不再读取）
- Zip 里打开的文件解压到 `~/Library/Caches/<应用标识>/zip/`；Agent 脚本在同目录的 `agent/` 下
- `keymap.json`：覆盖快捷键，例如 `{"trash": ["Cmd+Alt+Backspace"], "tab.new": []}`；动作 ID 见 `actions.go` 或速查表搜索。设置的快捷键页改键也写这个文件；同键双击写作 `"n n"`，不支持其他序列。冲突规则：覆盖的键优先于默认键（原动作失去该键）；两个覆盖抢同一个键时，按动作顺序靠前的得到；未知动作和写错的键忽略

## 技术验证结论（阶段 0）

| 项目 | 结论 |
|---|---|
| 原始字符输入（过滤输入框） | ✅ `ObserveInput` 能收到 `InputText` |
| 1 万文件目录 | ✅ 读取 + 排序约 50 ms（`go test -bench Open10k ./internal/pane`）；表格只构建可见行 |
| 图片显示 | ✅ `ui.DecodeBitmap` + `ui.Image` |
| 嵌套分栏 | ✅ `ui.Split` 可嵌套 |
| 资源 | App 10 MB；两栏各开 1 万文件目录时空闲 CPU 0%，内存约 86 MB（启动峰值约 200 MB，随后回落） |
| 阶段 3 回归 | 两栏都在本仓库（显示 Git 状态）时空闲 CPU 0%，内存约 50 MB |
| 阶段 4 回归 | 打包后的 app（10 MB，`Apple_self_dev` 签名）打开本仓库：空闲 CPU 0%，内存约 44 MB（top MEM；RSS 约 114 MB） |
| 阶段 5 回归 | 打包后的 app（10.4 MB）打开本仓库：空闲 CPU 0%，top MEM 约 73–82 MB；同一时间、同样方式测阶段 4 的包为 75–79 MB，没有退化（与阶段 4 当时的 44 MB 差在测量环境）。检测字体（`ui.FontFamilies`）约增加 2 MB。`Open10k` 基准与主分支持平（约 25 ms） |
| 阶段 13 性能测试（2026-11-11） | 打包后的 app（15 MB，Apple_self_dev）。**启动到窗口出现** 530–550 ms（6 次；带 1 万文件目录参数同样 537–567 ms）；拆分：Go 代码就绪约 5–10 ms，MyGo/AppKit 启动到 `WhenReady` 约 130 ms，建窗口与菜单约 60 ms，首帧构建 6–10 ms，其余为窗口首次呈现；对照同机最小 MyGo 窗口（一行文字）约 425 ms，应用自身只多约 50–100 ms。**空闲**：内存 phys_footprint 58 MB（启动峰值 145 MB），CPU 稳态 60 s 内 0.08 s CPU 时间（约 0.1%），top 0.0–0.1%。**1 万文件目录**：读取 + 排序 25 ms / 10.8 MB 分配（`Open10k`）；进入目录到首帧约 45 ms（`BenchmarkEnter10k`，含返回共 50 ms）；之后空闲帧 0.18 ms、光标下移一行 0.7 ms；显示该目录时内存 71–72 MB（+13 MB），空闲 CPU 30 s 内 0。测法：`scratchpad` 的 Swift 小工具轮询 `CGWindowListCopyWindowInfo` 计时；`footprint`、`ps -o time` 取内存与 CPU；UI 基准见 `bench_view_test.go`（`go test -run '^$' -bench 10k .`） |
| 对照：原生 Finder（同日同机同方法） | Finder 常驻、无法冷启动（不杀进程以免关掉用户窗口），改测**已运行时 `open` 一个小文件夹到新窗口出现**：首次 695 ms，之后 294–312 ms（含 `open` 进程开销）。**空闲**：phys_footprint 183 MB，CPU 60 s 内 0.22 s（约 0.4%）。**打开 1 万文件目录**：新窗口出现 311–547 ms；打开后 10 s 内耗 CPU 1.3–2.1 s（goFinder 启动并显示同一目录全程约 0.4 s）；内存首次 +51 MB（189→240 MB），再开 +3 MB；显示该目录时空闲 CPU 约 0.5%。结论：goFinder 冷启动比 Finder 打开新窗口慢约 0.2 s（MyGo 框架启动成本），但内存约为 Finder 的 1/3、处理 1 万文件的 CPU 约为 1/4–1/5 |

为了省资源：不用 WebView，插件只用 SF Symbols 和 updater，不加载系统文件图标（用本机已装的 Nerd Font 字形，没装时用文字符号），检查器默认关闭，QuickLook 只在光标停留后按需生成并缓存，监听只用最便宜的 HintsOnly 模式。
